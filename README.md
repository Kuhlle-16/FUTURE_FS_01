
**Kuhle Bikitsha**

This project is a personal portfolio website built to showcase my skills, projects, and experience as a software development student. It serves as a central platform where recruiters, collaborators, and peers can learn more about my work, technical abilities, and professional journey.

The portfolio is designed with a modern, clean interface and focuses on usability, responsiveness, and performance.

**Live Demo**
Deployed site: https://kuhlebikitsha.netlify.app/

**Repository**
GitHub repository: https://github.com/Kuhlle-16/FUTURE_FS_01.git

**Tech Stack**
**Frontend**
- React
- TypeScript

**Styling & UI**
- Tailwind CSS
- shadcn/ui components

**Form Handling**
- HTML form integrated with Formsubmit.co for handling contact form submissions

**Deployment**
 - Netlify

**Features**
- Responsive design optimized for desktop and mobile devices
- Clean and structured layout for showcasing projects and skills
Contact form with external form handling (no backend required)
Fast performance using Vite build tooling
Reusable UI components with consistent styling
